Q&A

모델별 구성은 어떻게 다른가요?

베이직은 식기 1개, 듀얼은 식기 2개 구성입니다. 스마트 듀얼은 식기 2개와 앱·영상 확인 기능을 제공합니다. 위 모델 비교표에서 한눈에 확인해 보세요.

앱은 어떤 모델에서 사용할 수 있나요?

앱 연동과 실시간 영상 확인은 스마트 듀얼 모델 전용 기능입니다. 베이직과 듀얼은 본체에서 예약 급여를 설정하는 구성입니다.

배송과 A/S는 어떻게 진행되나요?

현재 멍냥랩은 수업 실습용 브랜드로 실제 판매·배송·A/S를 진행하지 않습니다. 모델과 가격, 기능은 홈페이지 구성 연습을 위한 예시입니다.

    멍냥랩은 성동 SESAC 수업에서 제작한 교육용 브랜드입니다. 실제 상품 판매·배송·결제는 이루어지지 않습니다. 관심 신청은 입력 정보가 저장되지 않는 체험 기능입니다.
    개인정보 미수집 · 즉시 파기

    개인정보 처리 안내

    1. 입력하신 정보는 절대 저장하지 않습니다. 서버, 데이터베이스, 스프레드시트, 이메일, 외부 서비스 어디로도 전송되지 않습니다.

    3. 페이지 제작자와 강사를 포함한 누구도 입력값을 볼 수 없습니다.
